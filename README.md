# KanbanV2

University project: a JavaFX Kanban board. Tasks have a title, description, priority (Low, Medium, High, TurboImportant, each with an icon) and a date. They move between To do, In progress and Done columns, The board can be saved to and opened from a serialized file, and imported from or exported to CSV (examples in `src/data/`).

Open in IntelliJ IDEA with a JDK that includes JavaFX (e.g. Java 8) and run `kanban.Main`.
